# 🏫 SchoolPro – School Management System

**SchoolPro** is a modern, responsive, and user-friendly School Management System designed to simplify everyday school administration. It provides a centralized dashboard to manage students, teachers, classes, attendance, grades, examinations, fees, timetables, and parent communication.

This project is developed using **HTML5, CSS3, and JavaScript**, with LocalStorage for storing demo records directly in the browser.

## ✨ Features

- **Login & Registration:** Role-based login interface for Admin, Teacher, and Parent.
- **Dashboard:** Overview of school activities, statistics, and charts.
- **Student Management:** Add, edit, delete, search, filter, and export student records.
- **Teacher Management:** Maintain teacher details and subject information.
- **Class & Section Management:** Organize classes, sections, classrooms, and class teachers.
- **Attendance Management:** Maintain student attendance records.
- **Grade Management:** Store examination marks and academic records.
- **Timetable Management:** Organize class schedules, subjects, and teachers.
- **Exam Management:** Maintain examination schedules and details.
- **Fee Management:** Track fee categories, amounts, payments, and pending dues.
- **Parent Communication:** Maintain parent details and communication records.
- **Reports & Analytics:** View school record summaries and export CSV reports.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Works across desktop, tablet, and mobile screens.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Log in using the demo administrator credentials.

## 💾 Data Storage

SchoolPro uses browser LocalStorage to save demonstration records. Data remains available in the same browser unless its site data is cleared.

**Note:** This is a frontend demonstration project. It does not currently use a backend server or database. Login and role-based access are not suitable for production security.

## 🎯 Project Objective

The main objective of SchoolPro is to demonstrate how a digital school management platform can organize administrative and academic information through a simple and accessible interface.
